las cosas por dentro

Cada laboratorio es un entorno interactivo: desmonta el objeto, toca cada pieza para saber qué hace y juega con los mandos para ver el efecto en directo.

Todo funciona en el navegador, sin instalar nada. Arrastra para girar, rueda para acercarte, clic en una pieza para su ficha.
