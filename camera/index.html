    Cómo usar el laboratorio

    • Arrastra para girar la vista, rueda para acercarte, clic derecho para desplazarte.
    • Pasa el ratón / haz clic sobre cualquier pieza para ver qué hace y cómo afecta a la luz.
    • Arrastra el anillo de enfoque (goma estriada) arriba/abajo para mover el plano de enfoque.
    • Arrastra el anillo dentado de latón para abrir/cerrar el diafragma.
    • Los rayos de colores salen de tres puntos de la maqueta. Si se juntan en un punto sobre el sensor, ese objeto sale nítido; si llegan como un disco, sale borroso.
    • La pantalla del fondo y la vista previa muestran la foto real: profundidad de campo, exposición, ruido ISO y trepidación.
